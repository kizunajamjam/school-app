# school-app

サッカースクール向けの出欠管理アプリです。

スクールの練習・試合ごとに、**保護者がスマホから子どもの出欠を入力**し、**運営者がまとめて把握**できます。
LINE やメールでの出欠連絡を一本化することを目的にしています。

> 特定の1スクール専用として設計しています。保護者が複数スクールに所属する想定はありません
> （1人の保護者が複数の子どもを通わせる想定はあります）。

## 主な機能

### 運営者（管理者）
- イベント（練習・試合）の作成・削除
- 出欠状況の一覧と集計（参加／欠席／未定の人数）
- 会員（子ども）一覧の閲覧、カテゴリー・クラスの割り当て
- カテゴリー（U-10 等）・クラス（火曜クラス等）のマスタ管理
- 保護者への招待リンクの発行・共有・失効
- 出欠の代理変更（変更履歴に運営者名が残る）

### 保護者
- 招待リンクからの参加
- 自分の子どもの登録・編集
- イベントごとの出欠入力
- 回答履歴の確認（運営者による代理変更も見える）

保護者に見えるのは自分の子どもの情報だけです。他の家庭の情報は表示されません。

## 技術スタック

- Next.js 16（App Router）/ React 19 / TypeScript
- Supabase（PostgreSQL + Auth + Row Level Security）
- Tailwind CSS v4

権限制御は Postgres の Row Level Security で行っています。アプリ側のチェックだけに頼らず、
データベース層で「誰がどの行を読めるか」を保証する設計です。

## ステータス

プロトタイプです。実運用にあたっては、少なくとも以下の対応が必要です。

- デモ用アカウントの削除、またはパスワード変更
- Supabase の「Confirm email」を有効に戻す（開発中は無効化しています）
- イベント前日などのリマインド通知（未実装）

# ロールと権限

school-app では、1つのスクールに対して2種類のロールがある。

| 機能 | 管理者 (admin) | 保護者 (guardian) |
| --- | --- | --- |
| スクール作成 | ✕（単一スクール専用のためアプリからは作れない） | ✕ |
| イベント作成・編集・削除 | ○ | ✕ |
| 出欠の締切設定 | ○ | ✕ |
| 締切後の出欠変更 | ○（訂正のため可） | ✕ |
| お知らせの受信 | ✕（自分の操作のため） | ○（イベントの追加・変更時） |
| イベント閲覧 | ○ | ○ |
| 出欠の閲覧 | ○（全会員分） | ○（自分の子どもの分のみ） |
| 出欠の入力・訂正 | ○（全会員、訂正目的） | ○（自分の子どものみ） |
| 会員（子ども）の閲覧 | ○（全件・保護者名つき） | ○（自分の子どものみ） |
| 会員（子ども）の登録・削除 | ✕（保護者が自分の子どもを管理） | ○（自分の子どものみ） |
| 会員の氏名・学年の編集 | ✕ | ○（自分の子どものみ） |
| 会員へのカテゴリー割り当て（1人1つ） | ○（全件） | ○（自分の子どものみ） |
| 会員へのクラス割り当て（掛け持ち可） | ○（全件） | ○（自分の子どものみ） |
| カテゴリー・クラスのマスタ管理 | ○ | ✕（選択のみ） |
| 招待リンクの発行・失効 | ○ | ✕ |

## MVPでの前提

- 運営者側の権限は単一ロール（管理者）のみ。コーチ等の権限分離は将来拡張。
- 保護者は必ずアカウント登録が必要（リンクのみの匿名入力は不採用）。
- 1人の保護者が複数の子ども（兄弟姉妹）を登録できる。1人の子どもの保護者は1名のみ（MVP）。
- カテゴリー・クラスは管理者が定義したものから選ぶ方式。保護者が登録時に選び、
  管理者が会員一覧から後で修正できる（実際の割り当ての決定権は運営側にあるため）。
- カテゴリー（U-10 等の学年区分）は1人1つ。クラス（火曜クラス等）は
  「火曜と土曜の両方に通う」掛け持ちがあるため複数選べる。
